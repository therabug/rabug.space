# Personal portfolio
Source code of my portfolio website.

# Features
+ SSR age counter (yes I spend time for this)
+ Blog

# How to setup
+ `bun install`
+ `cp .env.example .env`
+ Edit `.env` file according to your birthday
+ `bun run dev`
